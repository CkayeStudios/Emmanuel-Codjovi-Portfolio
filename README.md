# Emmanuel Codjovi — Portfolio

Portfolio responsive en français, avec direction artistique sombre et accents violets, galerie illustrée, filtres et fiches de présentation.

## Prévisualiser
Ouvrir `index.html` dans un navigateur. Conserver le dossier `assets` à côté du fichier.

## Avant publication
- Remplacer les images de démonstration par les réalisations authentiques d’Emmanuel.
- Compléter les logiciels et niveaux réellement maîtrisés.
- Ajouter une adresse e-mail professionnelle et les liens sociaux exacts.
- Les concepts visuels inclus sont des illustrations de démonstration, pas des travaux revendiqués comme réels.

## Mise en ligne
Décompresser l’archive puis déposer le dossier sur https://app.netlify.com/drop ou utiliser un hébergement statique.
